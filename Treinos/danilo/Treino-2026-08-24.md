## 📌 FUNDAMENTOS GERAIS

| Regra | Detalhe |
| :--- | :--- |
| **Aquecimento** | 5-10 min de cardio leve + 2 séries com 40-50% da carga (15-20 reps) |
| **Cadência** | Fase excêntrica (negativa) de 2 a 3 segundos |
| **Descanso entre séries** | Respeitar os intervalos indicados |
| **Progressão** | Aumentar carga ou repetições semanalmente |

---

## 📊 MÉTODOS UTILIZADOS

| Sigla | Nome | Explicação |
| :--- | :--- | :--- |
| **PC** | Progressão de Carga | Aumentar peso a cada série ou semana |
| **Drop** | Drop Set | Fazer reps, reduzir peso, continuar até a falha |
| **BI** | Bi-Set | Dois exercícios em sequência sem descanso |
| **RP** | Rest-Pause | Fazer reps, descansar 10-15s, fazer mais reps |
| **Pico** | Pico de Contração | Segurar 2 segundos no ponto de maior tensão |
| **Falha** | Série Máxima | Ir até a falha concêntrica |

### ⚠️ Observações Importantes

| Tópico | Recomendação |
| :--- | :--- |
| **Vesícula Biliar** | Espalhe a gordura ao longo do dia. Evite refeições monstruosamente gordurosas. Óleo de coco (TCM) é mais fácil de digerir. Use 1 colher de sopa por refeição principal. |
| **Frutas/Legumes** | Baixo IG (brócolis, couve, espinafre, morango, maçã, pera) nos horários calmos. Frutas doces (banana, batata-doce) no pré/pós-treino. |
| **Água** | 3 a 4 litros por dia. |
